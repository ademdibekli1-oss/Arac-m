# Aracım — Güvenli Yama Aracı

HTML dosyalarına (veya ZIP projelere) güvenli, geri alınabilir yamalar uygulayan, telefona uygulama olarak kurulabilen (PWA) Türkçe bir araç.

## Özellikler
- Yama motoru: metnin önüne/sonuna ekle, değiştir, regex, JS ile dönüştür
- Canlı önizleme (varsayılan sandbox'lı güvenli mod), fark karşılaştırma, test paneli
- YZ asistanı (OpenRouter, OpenAI, Anthropic, Gemini, Ollama…)
- GitHub'a tek commit ile yükleme, yayın öncesi denetim, PWA paketleyici
- Çıktı dosyasının adını kendin belirleme (İndir sekmesi)

## Kullanım
1. **Dosya** sekmesinden `index.html` veya `.zip` seç.
2. **Yamalar** sekmesinde yama ekle ya da **Şablon**'lardan seç.
3. **Önizle** ile kontrol et, **İndir**'de dosya adını yazıp indir.
